# Aniruddh Paralikar — Enterprise AI Transformation Leader & Architect

Executive architecture portfolio detailing enterprise AI platforms, multi-agent orchestration systems, governed RAG architectures, and AI Centers of Excellence (CoE) operating models.

## Overview & Core Capabilities

- **16+ Years Experience**: Enterprise AI transformation leadership across global consulting, pharmaceutical, financial, legal, and industrial sectors.
- **Enterprise AI Stack**: Powered by Microsoft Foundry (Azure AI Foundry), Azure AI Search, Azure Logic Apps, Model Context Protocol (MCP), OpenAI GPT-5.6 Sol & o3-mini, Claude Sonnet 4.7 / Sonnet 5, LangGraph, Deep Agents, AutoGen, and Arize Phoenix observability.
- **18 Enterprise Case Studies**: Comprehensive portfolio spanning Signature Platform Flagships, Governed Business Systems, Reusable Workflow Suites, and Specialized AI Solutions.

## Architecture Highlights

- **Agentic Studio**: Governed citizen-development platform featuring 120+ agent blueprints, state checkpointing, and streaming security proxy guardrails.
- **Unified Enterprise Knowledge Engine**: Permission-aware RAG platform built on Microsoft Fabric and Azure AI Search with document-level ACL inheritance.
- **Trusted AI Control Tower**: Enterprise observability hub combining OpenTelemetry tracing, Cosmos DB, PowerBI metrics, and Arize Phoenix evaluation tracing.
